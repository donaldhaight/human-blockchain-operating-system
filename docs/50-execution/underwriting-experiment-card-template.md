# Underwriting Experiment Card Template

## Purpose

Use this template to convert a material proposition into a bounded, evidence-led experiment. The card starts an assertion at zero. It does not create a company, valuation, commercial entitlement, legal conclusion, insurance determination, financial commitment, or public claim.
