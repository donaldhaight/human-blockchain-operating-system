# Risks and Review Gates

| Risk | Required gate |
|---|---|
| Securities/investment characterization | Securities counsel before investor-oriented solicitation, rights, or money |
| Insurance formation, reciprocal, attorney-in-fact | Insurance regulatory counsel and applicable regulator |
| Adjusting, claim representation, appraisal, legal practice | Role/jurisdiction analysis before permissions |
| Escrow, custody, money transmission, payment settlement | Financial-regulatory counsel and qualified providers |
| Customer/policyholder/claim data | Privacy, security, consent, retention, and provider review |
| RRCA–USA LLC or founder related-party transactions | Conflict disclosure, independent review, valuation, approvals |
| S-corporation compatibility | CPA/tax counsel before special economics or new ownership |
| Automated work allocation and ratings | Fairness, explainability, appeal, accommodation, anti-gaming tests |
| Public performance, valuation, partnership, or endorsement claims | Evidence and authorized disclosure review |
| Production permission, money, legal, or publication changes | Named human approval and audit event |
| Agent overreach, prompt injection, or unintended external commitment | Least-privilege tool access, untrusted-input handling, named human gate, attributable action record, and revocation path |
| Agent-generated code or documentation defect | Automated checks, independent review, controlled release, monitoring, and recovery plan |
| Venture-studio capital activity, investment advice, or securities characterization | Securities, investment-management, tax, entity, custody, conflicts, disclosures, and authority review before solicitation, acceptance, deployment, advice, or public representation |
| Venture portfolio related-party conflicts, contribution rights, or implied ownership | Conflict disclosure, IP/contribution record, independent review where material, and documented approval before transaction or external representation |
| InsurTech product characterization or jurisdictional licensing | State-specific insurance, agency/producer, adjusting, claims-administration, data, consumer-protection, and entity review before pilot expansion, public representation, or regulated functionality |
| AI-influenced coverage, claims, underwriting, pricing, routing, or adverse action | Protected-action block, human authority, explainability, documented data basis, fairness/accuracy testing, and professional review before use in a consequential decision |
| Claim/project evidence, consent, or authority misrepresentation | Immutable attributable record, versioned consent, authority source, negative permission tests, correction path, and accountable review |
| Unauthorized practice of law, corporate practice, attorney-of-record misrepresentation, fee sharing, or nonlawyer control | Jurisdiction-specific professional-responsibility, entity, ownership/control, compensation, advertising, engagement, and supervision review before attorney-network activation or external legal-service representation |
| Attorney-client privilege, confidentiality, conflict, or client-choice failure | Lawyer-controlled conflict/capacity review, separate engagement, data-access limits, client-choice notice, information-sharing authorization, matter retention, and incident/withdrawal process |
| Conflation of reciprocal attorney-in-fact with attorney-at-law or attorney of record | Separate insurance-management and legal-services records, terminology controls, authority tests, counsel review, and no public claim until exact role is approved |
